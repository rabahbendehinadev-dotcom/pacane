==================================================
BUSINESS CONTEXT
==================================================

We already have:
- products
- workers / responsables de préparation
- product -> worker assignment
- automatic replenishment / bon de commande page
- branch-specific replenishment calculations

New expected workflow:
1. Manager calculates automatic replenishment.
2. Products are grouped by worker.
3. Manager clicks "Envoyer aux ouvriers".
4. ERP creates preparation orders, one per worker.
5. Each worker logs in and sees only their own assigned orders in "Mes préparations".
6. Worker can update order status:
   - Nouveau
   - Vu
   - En cours
   - Terminé

Important:
This is a WORK ORDER workflow only.
It must NOT:
- move stock
- create production stock movements
- change replenishment math
- affect sales or revenue
