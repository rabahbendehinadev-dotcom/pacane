====================================================

- purchase/reception main record
- supplier info
- user info if available
- items/lines
- linked products
- stock movements
- cash/caisse movements
- supplier ledger/debt movements
- supplier returns linked to this reception
- audit logs if available

Security rules:
1. Route requires authentication.
2. Use auth.organizationId.
3. Never trust organizationId from client.
4. Return 404 if the reception does not belong to current organization.

6. Do not return sensitive user fields.
7. Handle missing old data safely.
