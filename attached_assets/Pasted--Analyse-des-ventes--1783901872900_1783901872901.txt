أريد تطوير نظام الفلاتر داخل صفحة:

Analyse des ventes

دون إنشاء صفحة جديدة ودون تغيير أي منطق موجود حالياً.

الهدف هو إضافة فلاتر احترافية وسريعة تسمح للإدارة بتحليل المبيعات بدقة حسب المحل، المنتج، البائع، العميل، والفترة.

## 1. مكان الفلاتر

أضف قسم Filtres avancés داخل أعلى نفس صفحة Analyse des ventes، قبل البطاقات والإحصائيات.

على الكمبيوتر:
- تظهر الفلاتر في صفوف منظمة.

على الهاتف:
- تظهر داخل زر باسم:
  Filtres
- عند الضغط يفتح Bottom Sheet أو Drawer مرتب.
- لا تجعل الفلاتر توسع الصفحة أو تسبب Horizontal Scroll.

## 2. الفلاتر الأساسية

أريد إمكانية التصفية حسب:

- الفترة:
  - اليوم.
  - آخر 7 أيام.
  - آخر 30 يوماً.
  - هذا الشهر.
  - الشهر السابق.
  - هذه السنة.
  - تاريخ مخصص من / إلى.

- المحل أو الفرع.
- البائع.
- المنتج.
- الفئة.
- العميل.
- طريقة الدفع.
- نوع الوثيقة.
- حالة البيع.
- المبيعات مع Remise فقط أو بدون Remise.
- سبب التخفيض.
- قيمة التخفيض من / إلى.
- نسبة التخفيض من / إلى.
- رقم الفاتورة.

## 3. فلتر المحل

عند اختيار محل معيّن:

- تظهر فقط مبيعات ذلك المحل.
- قائمة البائعين تتحدث تلقائياً وتعرض بائعي ذلك المحل فقط.
- قائمة المنتجات يمكن أن تعرض المنتجات المتوفرة أو المباعة في ذلك المحل.
- جميع البطاقات والرسوم والجداول تتحدث حسب المحل المختار.

أضف خيار:
Toutes les boutiques

## 4. فلتر البائع

عند اختيار بائع:

- تظهر مبيعاته فقط.
- إجمالي رقم الأعمال الخاص به.
- عدد المبيعات.
- مجموع التخفيضات التي منحها.
- متوسط panier.
- المنتجات التي باعها.
- العملاء الذين تعامل معهم.
- أداؤه مقارنة بباقي البائعين.

أضف خيار:
Tous les vendeurs

## 5. فلتر المنتج

أريد Select قابل للبحث لأن عدد المنتجات كبير.

يجب أن يدعم البحث حسب:

- اسم المنتج.
- Code produit.
- SKU.
- Barcode.
- IMEI أو Serial إذا كان موجوداً.

عند اختيار منتج:
- تظهر مبيعات هذا المنتج فقط.
- الكمية المباعة.
- رقم الأعمال.
- الربح.
- التخفيضات.
- الفروع التي باعت المنتج.
- البائعون الذين باعوه.

أضف خيار:
Tous les produits

## 6. الفلاتر المترابطة

الفلاتر يجب أن تكون مترابطة.

مثال:
إذا اخترت Boutique BEN OMAR:
- قائمة البائعين تعرض فقط بائعي BEN OMAR.
- النتائج تعرض فقط مبيعات BEN OMAR.

إذا اخترت بعدها البائعة Safa:
- النتائج تصبح مبيعات Safa داخل BEN OMAR فقط.

إذا اخترت منتجاً:
- النتائج تصبح مبيعات ذلك المنتج بواسطة Safa داخل BEN OMAR.

## 7. تحديث جميع الأقسام

بعد تطبيق أي فلتر، يجب تحديث كل محتوى Analyse des ventes، وليس الجدول فقط:

- CA brut.
- CA net.
- Encaissé.
- Panier moyen.
- Créances.
- Clients actifs.
- Remise totale.
- Taux de paiement.
- عدد المبيعات.
- عدد المنتجات.
- جميع الرسوم البيانية.
- ترتيب البائعين.
- تحليل المنتجات.
- Analyse Remises.
- الجداول.
- التقارير والتصدير.

## 8. واجهة الفلاتر

أضف في الأعلى ملخصاً للفلاتر النشطة على شكل Chips مثل:

- Boutique: BEN OMAR
- Vendeur: Safa
- Produit: X
- Période: Ce mois

كل Chip يمكن حذفه وحده.

أضف الأزرار:

- Appliquer les filtres
- Réinitialiser
- Enregistrer ce filtre

ويظهر عدد الفلاتر النشطة داخل Badge.

## 9. حفظ الفلاتر

أريد أن يستطيع المستخدم حفظ مجموعة فلاتر باسم معين، مثل:

- Ventes Safa — BEN OMAR
- Remises du mois
- Produit X — Toutes boutiques

ويمكنه استعمالها لاحقاً بسرعة.

يجب أن تكون الفلاتر المحفوظة خاصة بكل مستخدم.

## 10. الرابط والمشاركة

احفظ الفلاتر داخل URL query parameters حتى:

- لا تضيع عند تحديث الصفحة.
- يمكن الرجوع لنفس التحليل.
- يمكن مشاركة الرابط مع مستخدم لديه صلاحية.

مثال:

/analytics/sales?branch=2&seller=8&product=45&period=this_month

## 11. الصلاحيات

احترم صلاحيات المستخدم:

- المستخدم الذي يرى محلاً واحداً لا يظهر له باقي المحلات.
- البائع العادي يرى بياناته فقط إن كانت الصلاحيات تفرض ذلك.
- المدير يرى جميع المحلات والبائعين.
- لا تعرض أي بيانات غير مسموحة عبر API حتى لو تم تعديل URL يدوياً.

## 12. الأداء

لأن البيانات كثيرة:

- طبق الفلاتر في Backend وليس في Frontend فقط.
- لا تحمل جميع المبيعات ثم تصفيها في المتصفح.
- استعمل استعلامات SQL محسنة.
- أضف indexes عند الحاجة.
- استعمل debounce في البحث عن المنتجات والعملاء.
- استعمل Pagination للجداول.
- ألغِ الطلب السابق إذا غيّر المستخدم الفلتر بسرعة.
- أضف Loading واضح بدون تجميد الصفحة.

## 13. التصدير

عند تصدير CSV أو Excel أو PDF:

- يجب تصدير النتائج المفلترة فقط.
- أضف في رأس التقرير:
  - الفترة.
  - المحل.
  - البائع.
  - المنتج.
  - تاريخ إنشاء التقرير.
  - اسم المستخدم الذي أنشأه.

## 14. الهاتف

على iPhone وAndroid:

- الفلاتر تفتح داخل Bottom Sheet أو Drawer.
- كل Select يأخذ عرض الشاشة كاملاً.
- البحث عن المنتج يكون سهلاً.
- زر Appliquer يبقى واضحاً أسفل النافذة.
- لا يوجد Horizontal Scroll على مستوى الصفحة.
- لا تغلق النافذة قبل أن يضغط المستخدم Appliquer أو Annuler.

## 15. مهم جداً

- لا تنشئ صفحة جديدة.
- لا تحذف أي بطاقة أو رسم بياني.
- لا تغير طريقة الحساب الحالية إلا إذا وجدت خطأ حقيقياً.
- أضف فقط نظام الفلاتر فوق صفحة Analyse des ventes الحالية.
- حافظ على نفس Design System.
- اختبر دقة النتائج عند الجمع بين أكثر من فلتر.
- اختبر Production Build.
- تأكد أن الفلاتر تعمل على الكمبيوتر والهاتف وداخل PWA.

قبل التنفيذ:
اعرض لي أولاً الـAPI parameters المقترحة، الاستعلامات التي ستتغير، والـcomponents التي ستُضاف.
