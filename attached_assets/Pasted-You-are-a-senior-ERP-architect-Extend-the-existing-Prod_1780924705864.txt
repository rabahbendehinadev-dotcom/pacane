You are a senior ERP architect.

Extend the existing Production + BOM system with a full COSTING ENGINE (COGS) for recipes, including semi-finished products, nested BOM, and real-time profitability calculation.

This is Phase 2 of the system.

==================================================
1. OBJECTIVE
==================================================

We want to calculate:

- Cost per recipe (FINISHED + SEMI-FINISHED)
- Cost per production order
- Real-time ingredient cost impact
- Profit margin estimation
- Waste / loss tracking

This must work with recursive BOM (Phase 1 system).

==================================================
2. CORE COSTING LOGIC
==================================================

Each recipe must compute:

TOTAL COST = SUM of all ingredients + sub-recipes costs

Rules:
- If item_type = PRODUCT → take purchase cost from stock table
- If item_type = RECIPE → recursively calculate cost of that recipe
- Quantity multiplier must be applied at every level
- Currency always DA

- last_cost_update

## production_order_items (NEW if not existing)
- id
- production_order_id

- quantity
- unit_cost
- total_cost

==================================================
4. COST ENGINE FUNCTION
==================================================

Implement:

calculateRecipeCost(recipeId)

AND

calculateProductionCost(productionOrderId)

Logic:

- Walk recursively through BOM tree
- Fetch latest stock purchase cost for raw materials
- Multiply quantities at each level
- Aggregate cost safely
- Cache results for performance

==================================================

Show:

- Total estimated cost

- Cost per sub-recipe breakdown
- Total quantity impact
- Expected cost per unit

==================================================
6. PROFITABILITY ENGINE
==================================================

If product has selling price:

profit = selling_price - cost_per_unit
margin% = (profit / selling_price) * 100

Display:

- profit per unit
- total profit per production batch
- margin color indicator:
  - green > 30%
  - orange 10–30%
  - red < 10%

==================================================
7. STOCK COST INTEGRITY
==================================================

Rules:

- NEVER overwrite purchase cost history
- Always use last known valid purchase price
- If multiple purchase prices exist → use weighted average cost
- If no cost found → flag warning

==================================================
8. WASTE / LOSS TRACKING (NEW MODULE)
==================================================

Add optional field in production:

- waste_percentage (default 0%)

Apply:

final_cost = theoretical_cost + waste_cost

Waste is calculated per recipe:
- ingredient loss
- production inefficiency

==================================================
9. CACHE STRATEGY
==================================================

To avoid performance issues:

- Cache recipe cost result
- Invalidate cache when:
  - stock cost changes
  - recipe modified
  - production completed
